## D_PlaySound

```c
int D_PlaySound(string soundName)
```

### Описание
Воспроизвести звук во время выполнения диалога. После выбора ответа воспроизведение останавливается

### Параметры
* **soundName** - название звукового файла который будет воспроизведён. Путь задаётся из директории `sounds\dialogs`.

### Заметки
[Особенности выполнения диалогов](../AgeScript.md#особенности-выполнения-диалогов)

### Возвращаемое значение
Возвращает 0

### Пример
```c
// Пример одной ветки диалога с воспроизведением озвучки и выбором из 2 вариантов ответа
if (dialog_branch == 0)
{	
	test = D_Say(10);
	test = D_PlaySound("kotar\zdravstvuj_rasskazhi.ogg");
	test = D_Answer(8);
	test = D_Answer(6);
	dialog_branch = 1;
}
```
