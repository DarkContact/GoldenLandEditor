## LE_CastEffect

```c
int LE_CastEffect(string groupName, string magicTechName, int x, int y)
```

### Описание
Отобразить закицленный визуальный эффект в локации.  
Чаще всего используется для анимаций огня (факелы, костры).

### Параметры
* **groupName** - название группы эффектов, используется в `LE_DelEffect` для их удаления
* **magicTechName** - название магического эффекта (эффекты описаны в `scripts\magic.scr` и `sdb\magic\magictechnames.sdb`)
* **x** - координата x (в пикселях) где отобразить центр эффекта
* **y** - координата y (в пикселях) где отобразить центр эффекта

### Заметки
Для простоты поиска координат можно выполнить в консоли `d_info_world 1`.  

Параметр `time_apply` (время в мс) из `scripts\magic.scr` влияет на то когда начнётся повторное воспроизведение эффекта.   
Если `time_apply < totalDuration`, то будет запущено несколько анимаций наложенных друг на друга, а если `time_apply >= totalDuration` эффект будет аналогичен `LE_CastMagic`.  
К примеру totalDuration = 1000 мс, а time_apply = 300 мс. Значит эффект будет запущен ещё 3 раза в 300 мс, 600 мс и 900 мс соотвественно, пока идёт воспроизведение основного эффекта. Каждый из запущенных таким образом эффектов рекурсивно запускает новые эффекты, поэтому нужно быть аккуратнее с заданием параметра `time_apply` и не задавать его слишком маленьким.  
Если у эффекта есть звук - он будет также циклически воспроизводиться

### Возвращаемое значение
Возвращает 0

### Пример
```c
test = LE_CastEffect("center", "effect_fire_smallest", 1290, 234);
```
