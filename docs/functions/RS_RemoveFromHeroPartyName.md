## RS_RemoveFromHeroPartyName

```c
int RS_RemoveFromHeroPartyName(string npcTechName)
```

### Описание
Убрать NPC из группы

### Параметры
* **npcTechName** - техническое имя NPC

### Возвращаемое значение
Возвращает 0

### Пример
```c
result = RS_RemoveFromHeroPartyName("L0.PWolf");
```
