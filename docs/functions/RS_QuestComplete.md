## RS_QuestComplete

```c
int RS_QuestComplete(string questTechName)
```

### Описание
Завершить квест

### Параметры
* **questTechName** - название квеста, задаётся из `sdb\diary\single_quest_tech.sdb`

### Заметки
Зачёркивает квест в дневнике.  
Обычно последний шаг выполнения квеста задаётся такой последовательностью `RS_StageEnable`, `RS_StageComplete`, `RS_QuestComplete`, таким образом в дневнике сразу создаётся новая запись которая перечёркнута и отображается иконка позволяющая понять что квест завершился.

### Возвращаемое значение
Возвращает 0

### Пример
```c
result = RS_QuestComplete("starosta"); // Зачёркивает квест в дневнике, т.е. теперь он считается выполненым
```
