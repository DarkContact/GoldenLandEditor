## Cmd

```c
int Cmd(string command)
```

### Описание
Выполнить строку в отладочной консоли. [Список консольных команд](../ConsoleCommands.md)

### Параметры
* **command** - команда для выполнения через консоль

### Возвращаемое значение
Возвращает 0

### Пример
```c
// Скрыть игровую панель
result = Cmd("show_panel 0");

// Вывести значение переменной в консоль
int var;
var = 255;
result = Cmd("var");
```
