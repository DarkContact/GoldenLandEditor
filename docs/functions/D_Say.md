## D_Say

```c
int D_Say(int dialogPhraseId)
```

### Описание
Задать реплику, которая отображается в диалоге синим шрифтом и обозначает то что говорят игроку

### Параметры
* **dialogPhraseId** - id строки диалога из файла `sdb\dialogs\dialogsphrases.sdb`

### Заметки
[Особенности выполнения диалогов](../AgeScript.md#особенности-выполнения-диалогов).  
Реплика должна быть одна. Если будет несколько вызовов `D_Say` подряд, то будет показана последняя реплика.

### Возвращаемое значение
Возвращает 0

### Пример
```c
// Пример одной ветки диалога с воспроизведением озвучки и выбором из 2 вариантов ответа
if (dialog_branch == 0)
{	
	test = D_Say(10);
	test = D_PlaySound("kotar\zdravstvuj_rasskazhi.ogg");
	test = D_Answer(8);
	test = D_Answer(6);
	dialog_branch = 1;
}
```
