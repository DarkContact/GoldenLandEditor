## D_CloseDialog

```c
int D_CloseDialog(int value)
```

### Описание
Завершить выполнение диалога

### Параметры
**value** - допустимо любое значение, но обычно здесь указывают 0 (из игровых примеров)

### Заметки
[Особенности выполнения диалогов](../AgeScript.md#особенности-выполнения-диалогов).  
Можно обойтись без этой функции, т.к. если после выбора ответа, не будет нового кода с `D_Say` и `D_Answer`, то диалог завершится автоматически.

### Возвращаемое значение
Возвращает 0

### Пример
```c
if (dialog_branch == 1)
{	
	test = D_CloseDialog(0);
}
```
