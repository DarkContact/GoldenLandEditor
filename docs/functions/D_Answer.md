## D_Answer

```c
int D_Answer(int dialogPhraseId)
```

### Описание
Задать реплику, которая отображается в диалоге с номером ответа и обозначает вариант ответа игрока

### Параметры
* **dialogPhraseId** - id строки диалога из файла `sdb\dialogs\dialogsphrases.sdb`

### Заметки
[Особенности выполнения диалогов](../AgeScript.md#особенности-выполнения-диалогов).  
Количество ответов может быть не больше 170, иначе будет вылет из игры. Рекомендуется создавать не больше 10 ответов, чтобы корректно работали горячие клавиши выбора ответов. Также dialogPhraseId должны быть уникальными для каждого ответа, чтобы отследить номер ответа и ответы корректно отображались в интерфейсе диалога.

### Возвращаемое значение
Возвращает 0

### Пример
```c
// Пример одной ветки диалога с воспроизведением озвучки и выбором из 2 вариантов ответа
if (dialog_branch == 0)
{	
	test = D_Say(10);
	test = D_PlaySound("kotar\zdravstvuj_rasskazhi.ogg");
	test = D_Answer(8);
	test = D_Answer(6);
	dialog_branch = 1;
}
```
