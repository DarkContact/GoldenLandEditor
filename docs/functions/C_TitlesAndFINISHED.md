## C_TitlesAndFINISHED

```c
int C_TitlesAndFINISHED(int userInterfaceId, int value)
```

### Описание
Показать анимацию текста и завершить игру

### Параметры
* **userInterfaceId** - id строки из `sdb\user_interface.sdb` будет показано в виде анимации текста который появляется слово за словом
* **value** - параметр завершения, если выбран 0, 1 или 2, то будет показано всплывающее сообщение с текстом из `sdb\user_interface.sdb` под ID 301, 302 и 303 соответсвенно. После закрытия сообщения будут показаны финальные титры. Если параметр отличается от 0, 1 или 2, то всплывающего сообщения не будет и сразу покажут титры.

### Заметки
Функция аналогичная `C_FINISHED` за исключением что сначала будет показана анимация текста

### Возвращаемое значение
Возвращает 0

### Пример
```c
result = C_TitlesAndFINISHED(320, 3);
```
