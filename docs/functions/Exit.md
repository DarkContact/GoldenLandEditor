## Exit
```c
int Exit(int value)
```

### Описание
Прервать выполнение скрипта

### Параметры
**value** - если значение > 0, то функция будет выполнена

### Возвращаемое значение
Возвращает 0

### Пример
```c
// В диалоге будет только 1 вариант ответа
result = D_Say(10);
result = D_Answer(8);
result = Exit(1);
result = D_Answer(6); // Выполнено не будет
```
