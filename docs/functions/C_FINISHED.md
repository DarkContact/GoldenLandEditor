## C_FINISHED

```c
int C_FINISHED(int value)
```

### Описание
Завершить игру и показать финальные титры

### Параметры
* **value** - параметр завершения, если выбран 0, 1 или 2, то будет показано всплывающее сообщение с текстом из `sdb\user_interface.sdb` под ID 301, 302 и 303 соответсвенно. После закрытия сообщения будут показаны финальные титры. Если параметр отличается от 0, 1 или 2, то всплывающего сообщения не будет и сразу покажут титры.

### Заметки
Если `C_FINISHED(3)` будет вызван из диалога, то обязательно сразу после нужно вызвать `D_CloseDialog(0)` иначе при запуске новой игры диалог продолжит выполнятся и будет невозможно продолжить игру.

### Возвращаемое значение
Возвращает 0

### Пример
```c
result = C_FINISHED(3);
```
